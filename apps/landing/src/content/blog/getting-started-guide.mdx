## Step 1: Create your workspace

After confirming your email, you'll land on the workspace setup screen. A workspace is the top-level container for everything your team builds — think of it as your organization's home base.

Give your workspace a descriptive name. Most teams use their company name, but a project or department name works just as well. You can rename it later from **Settings → General**.

> **Tip:** A single workspace is enough for most teams. Create additional workspaces only if you need hard isolation between groups (for example, separate clients or production vs. staging).

## Step 2: Invite your team

Software is a team sport. Invite collaborators from **Settings → Members** by entering their email address and choosing a role:

- **Owner** — full control, including billing and deletion.
- **Admin** — manage members and projects, but not billing.
- **Editor** — create and edit content within projects.
- **Viewer** — read-only access for stakeholders.

Roles are enforced everywhere, including the API, so you never have to worry about someone accidentally touching something they shouldn't.

## Step 3: Connect a data source

Most projects need data. [Startup Name] supports several connection types out of the box, and the connection wizard autodetects the most common ones.

Here's a minimal example of connecting a data source programmatically using our CLI:

```bash
# Install the CLI (one-time setup)
npm install -g @your-startup/cli

# Authenticate with your workspace
your-startup login

# Link a new data source
your-startup connect --name "production-db" \
  --type postgres \
  --url $DATABASE_URL
```

Once connected, your data source appears in the dashboard and is immediately available to any project in the workspace.

### Choosing the right connection type

Not sure which connector to use? Here's a quick reference:

| Need | Recommended source |
| --- | --- |
| Transactional records | PostgreSQL / MySQL |
| Event streams | Webhook / queue |
| File-based data | Object storage |
| Third-party APIs | REST integration |

## Step 4: Build and publish

With a workspace, a team, and a data source in place, you're ready to build. Click **New Project**, pick a template, and start dragging components onto the canvas. Changes save automatically and preview in real time.

When you're happy with the result, hit **Publish**. Your project goes live at a shareable URL instantly — no build step, no deploy pipeline, no waiting.
